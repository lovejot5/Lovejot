Daisy Documentation

Everything you need to set up, use, and enjoy Daisy in your Discord server.

Getting Started

Invite Daisy to your server, join a voice channel, and use /play to start playing music instantly.

Basic Usage

Daisy uses modern slash commands. Type / in chat to view all available commands and options.

Supported Platforms

Daisy supports music from popular platforms and automatically selects the best available source.

24/7 Mode

Enable 24/7 mode to keep Daisy connected to a voice channel without disconnecting when idle.

Permissions

Make sure Daisy has permission to connect and speak in voice channels. Server admins can restrict commands using Discord roles.

Troubleshooting

If Daisy is not playing music, check voice permissions, ensure you are in a voice channel, and try reusing the /play command.
