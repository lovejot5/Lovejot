Daisy Documentation

Everything you need to know to get started with Daisy.

Getting Started

Daisy is designed to be simple and intuitive. You can start using Daisy in your server within seconds.

  1. Click Add to Discord and invite Daisy.
  2. Join a voice channel.
  3. Use /play to start playing music.

Basic Usage

Play Music

Use /play followed by a song name or URL.

Manage Playback

Control music with /pause, /resume, and /skip.

Queue System

View upcoming tracks using /queue.

24/7 Mode

Enable continuous playback so Daisy stays connected.

Troubleshooting

Daisy is not playing music

Ensure Daisy has permission to join and speak.

Commands are not responding

Make sure slash commands are enabled and Daisy is online.

Audio quality issues

Check server region and internet stability.
