Getting Started

Daisy is built to be fast, simple, and reliable. You can start playing music in your Discord server in under a minute.

1

Invite Daisy

Add Daisy to your server using the official Discord invite.

2

Join Voice

Connect to a voice channel where you want music playback.

3

Play Music

Use /play with a song name or link to begin.

Basic Usage

Play Music

Use /play followed by a song name or URL to start playback.

Manage Playback

Control music using /pause, /resume, and /skip.

Queue System

View upcoming tracks using /queue.

24/7 Mode

Enable continuous playback so Daisy stays in the channel.

Troubleshooting

Daisy is not playing music

Make sure Daisy has permission to join and speak in your voice channel.

Commands are not responding

Ensure slash commands are enabled and Daisy is online.

Audio quality issues

Check your server region and internet connection stability.
