Privacy Policy

How Daisy handles your data and protects your privacy.

Information We Collect

Daisy only stores data required for core bot functionality. We do not sell or share user data.

1

Server IDs

Stored to remember settings like prefixes, filters, and music configurations.

2

User IDs

Used only for features such as playlists, premium status, or saved preferences.

3

Command Usage

Anonymous usage statistics may be collected to improve performance and reliability.

What We Do NOT Collect

Daisy does not store message content, voice data, private conversations, or personal user information.

Data Security

We implement security practices to protect stored data from unauthorized access or misuse.

Data Removal

Server owners can request data removal by contacting support. Upon request, all stored data linked to that server will be deleted.
